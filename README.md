# مجرة — النسخة المصغّرة (APK)

ملف التثبيت المضغوط لتطبيق «مجرة» — إدارة المواقع الشخصية (أوفلاين 100٪).

## الملف

| العنصر | القيمة |
|--------|--------|
| الملف | `majarra-mini-2.10.1.apk` (الأحدث) |
| الإصدار | 2.10.1-mini (versionCode 19) |
| الحجم | ~3.7 م.ب (مقابل ~59 م.ب لنسخة التصغير غير المضغوطة) |
| البناء | نمط `mini`: تصغير R8 + تقليص الموارد + توقيع مفتاح التصحيح |
| المتطلبات | Android 11+ (API 30) |
| المصدر | https://github.com/SagedAmV/app_work_kotlin |

## التثبيت

انقل الملف إلى جهازك وافتحه ثم وافق على التثبيت من «مصادر غير معروفة»
إن طُلب ذلك. التوقيع بمفتاح التصحيح يعني أن الجهاز قد يرفض تحديث نسخة
موقعة بمفتاح مختلف — ثبّتها كنسخة مستقلة.

## جلسة البناء (2.10.1)

بُنيت هذه النسخة في جلسة تحقق عميق مستقلة من أخطاء البناء على كود 2.10.0
(تجميع فعلي كامل: Gradle 8.5 + AGP 8.2.2 + Kotlin 1.9.22 + JDK 17).
التجميع كشف خطأين ترجمة حقيقيين في شاشة المجرة أُصلحا ورُفعا لمستودع
المصدر: (1) `fitAnim` كان يُستعمل في كتلة استقبال الترتيب الذكي قبل
تعريفه؛ (2) مؤقّت الضغط المطوّل لزر «ترتيب» كان يُطلق بـ`launch` ضمنيًا
داخل `awaitEachGesture` بينما `PointerInputScope` ليس `CoroutineScope`.
وفحص يدوي عميق إضافي أصلح انيميشن ذبول العقدة المحذوفة الذي كان ميتًا
منطقيًا. ثم أعيد البناء كاملًا ناجحًا بلا أي خطأ: ترجمة Kotlin وKSP
(Room + Hilt) ومترجم Compose وتصغير R8 كامل مع تقليص الموارد و`lintVital`
و43 اختبار وحدة ناجحًا بلا فشل. تتضمن هذه النسخة ميزة 2.10: زر «ترتيب»
بالضغط المطوّل على الفراغ في المجرة يعيد توزيع المواقع توزيعًا ذكيًا
(فصل المكونات + شجري شعاعي + قوة-موجهة متكيفة + تعبئة خلايا).
النسخ السابقة (`majarra-mini-2.9.1.apk` و`majarra-mini-2.9.3.apk`
و`majarra-mini-2.9.4.apk`) تبقى في المستودع للأرشفة.
