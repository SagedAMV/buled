## 🔄 v2.4.0 — ترتيب الواجهات

عندما تُرفض عملية لأن الرصيد لا يكفي، **لا تُرمى بياناتك**.

المثال: داخل حساب عميل → عملية **عليه** + البيان → رفض → شحن من بنك/كاش/حساب/ادخار/هدف → **تعود نفس واجهة عليه بنفس البيان** لإتمامها.

نُفّذ نفس الترتيب في:
- عمليات له/عليه (العملاء)
- صرف ودخل (الرئيسية والسجل)
- التحويل بين البنك والكاش
- الإضافة لهدف
- الإضافة للادخار

ومصادر شحن الرصيد الحقيقي صارت تشمل أيضاً **الادخار والأهداف**.
