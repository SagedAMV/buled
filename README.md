## 🛠️ ما الذي أُصلح في v2.1.2 (مراجعة شاملة)
- **استيراد النسخ الاحتياطية:** كان الاستيراد يتجاهل حسابات العملاء وعملياتهم
  وسجل التحويلات وحدود الفئات — الآن يستورد كل شيء مع إعادة ربط المعرفات
  (أهداف ← عمليات، عملاء ← حسابات ← عمليات ← تحويلات) فلا تضيع أي بيانات.
- **حماية التحويلات:** منع أي مسار جانبي يتجاوز فحص "لا صندوق سالب".
- **ذرّية الشحن/السحب الحقيقي:** معاملات ذرّية داخل قاعدة البيانات مع فحص
  مزدوج — يستحيل سباق يجعل الرصيد سالباً.
- **مخطط تطور المدخرات:** صار يبدأ من الرصيد الافتتاحي (كان يتجاهله).
- **تنظيف الكود:** إزالة التأكيدات القسرية !! وكتابة آمنة للحاسبة.

## 🐛 ما الذي أُصلح في v2.1.1
- عطل "النقر على عميل" (وسيط clientId المفقود) — الآن القراءة من وسائط الوجهة مباشرة.
