## التثبيت

انقل الملف إلى جهازك وافتحه ثم وافق على التثبيت من «مصادر غير معروفة»
إن طُلب ذلك. التوقيع بمفتاح التصحيح يعني أن الجهاز قد يرفض تحديث نسخة
موقعة بمفتاح مختلف — ثبّتها كنسخة مستقلة.

## جلسة البناء (2.12.2)

بُنيت هذه النسخة من التزام المستودع `2ad8d6e` بعد **جلسة التحقق العميق
الثامنة من أخطاء البناء** على الكود بهوية 2.12.1، في بيئة نظيفة أُعدّت
من الصفر بالكامل (OpenJDK 17.0.20 جديد + Android SDK 34 جديد عبر أدوات
سطر الأمر + أدوات بناء 34.0.0، وGradle 8.5 وAGP 8.2.2 وKotlin 1.9.22
بتنزيل الاعتماديات كاملة):

- نُفِّذ `assembleMini` كاملًا: نجح البناء (ترجمة Kotlin + KSP لـRoom
  وHilt + مترجم Compose + تصغير R8 كامل + تقليص الموارد + `lintVital`)
  **بلا أي خطأ وبلا تحذير Kotlin واحد**.
- نُفِّذ طقم اختبارات الوحدة كاملًا عبر الأنماط الثلاثة (تصحيح/إصدار/
  مصغّر): **46 اختبارًا × 3 أنماط = 138 تنفيذًا، 0 فشل** (خطوط المواد
  11، مدخلات المواقع 6، مدقق النزول الطارئ 7، تخطيط الشبكة 22).
- الفحص الشامل `lintMini`: **صفر أخطاء و11 تحذيرًا** كلها معروفة
  (10 اقتراحات ترقية اعتماديات لا تُنفَّذ عمدًا — سياسة التثبيت
  والأوفلاين — + 1 داخلي في مكتبة فحص Compose نفسها خارج سيطرة
  المشروع).
- الفحص اليدوي العميق سطّرًا سطرًا شمل: مطابقة الترحيل 7→8 مع
  الكيانات حرفيًا (جدول `material_requests` وأعمدة السحب الثلاثة
  الجديدة وملاحظات النزول)، ومطابقة دورة الموافقة/الرفض/الاسترجاع
  لطلبات الاحتياج ودورة السحب/قرار الإصلاح/الإرجاع مع نص تعليمات.md،
  ومسحًا آليًا شاملًا للدوال الخاصة والداخلية (63 دالة — كلها
  مستعملة، لا دوال ميتة)، ومسح TODO/FIXME و`@Deprecated` و`@Suppress`
  (نظيف)، ومراجعة منطق اللمس في شاشة المجرة (إعادة تهيئة المراجع عند
  تغيّر عدد الأصابع، قفل السحب أثناء انيميشن الترتيب، مؤقّت الضغط
  المطوّل من نطاق التركيب صراحة) وخطة الطوارئ في `NetworkLayout.
  arrange` (لا ترمي استثناءً ولا تُعيد نقصًا: ذكي ← قوة-موجهة ←
  شبكة). النتيجة: **صفر أخطاء بناء تُصلَح في الكود**.
- تحقّق الملف الناتج بـ`apksigner verify` (موقّع بمخطط v2) و`aapt2
  dump badging` (الحزمة `com.majarra.galaxy`، الرمز 27، الاسم
  `2.12.2-mini`، minSdk 30، targetSdk 34، لا أذونات إنترنت)، وبمحتوى
  الحزمة: ملفات خط «تجوال» الثلاثة فقط بمحتواها الكامل وملفّا «أريف
  رقعة» القديمان أثران صفريّان لمصغّر الموارد.
- ملاحظة: نسخة 2.12.1 (رمز 26) تبقى أدناه للرجوع؛ النسخة الحالية هي
  رمز 27 فقط.
