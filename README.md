## 🕊️ جديد v2.3.0 — الحركة الناعمة (Soft Motion)
كل الأنيميشنات أُعيدت ضبطها لتكون **ناعمة ومرئية للعين** — لا شيء عابر أو سريع:
- 🧭 **انتقالات الصفحات**: دخول بتلاشٍ + انزلاق + تكبر تدريجي (420-480ms) وخروج هادئ — العين تتابعها بسهولة
- 🕰️ **تأرجح الساعة للبطاقات**: كل بطاقة (أهداف، عملاء، حسابات، إحصائيات) تدخل بدوران كعقرب الساعة، ثم ترتد في الاتجاه المعاكس بتأثير الجاذبية، ثم تستقر بنعومة
- 💫 **ضغطة ناعمة على كل زر**: انكماش بطيء مرئي + وميض أبيض يضيء الزر ثم يعود للونه الطبيعي تدريجياً (620ms عودة)
- 📋 **خانات النوافذ تتتابع**: نوافذ الصرف والدخل والأهداف والتحويل — كل خانة تنزلق من الأسفل بنعومة بعد سابقتها بفاصل مريح (110ms)
- 🌊 **اهتزاز هادئ**: نافذة "رصيد غير كافٍ" تهتز بموجات بطيئة بسعة صغيرة (720ms) — تنبيه لا إنذار
- ⏱️ **العدّادات أبطأ وأوضح**: الأرقام تعدّ بوتيرة مرئية (380-600ms)
- ♿ كل الحركات تحترم إعداد "تقليل الحركة" في أندرويد

## ✨ من الإصدارات السابقة
- 🎬 شاشة افتتاحية متحركة (محفظة تقفز + اسم يتساقط حرفاً حرفاً)
- 🎉 قصاصات احتفال عند الدخل الجديد وإتمام الأهداف
- 🌈 تدرجات حية تتنفس + 🐷 حصالة تطفو
- 🎯 أعمدة تنمو بتتابع + عمود اليوم ينبض
- 🐛 إصلاحات: النقر على عميل، استيراد كامل، ذرّية الأرصدة
