## ✨ جديد v2.2.0 — الأنيميشن الشامل
- 🎬 **شاشة افتتاح متحركة**: محفظة تقفز بنابض واسم التطبيق يتساقط حرفاً حرفاً
- 🎉 **قصاصات احتفال (Confetti)** عند وصول دخل جديد وعند إتمام هدف 100%
- 💫 **ضغطة نابضة في 32 موضعاً**: كل الأزرار والصفوف والشرائح تنضغط وترتد بنابض
- 🌈 **تدرج حي يتنفس** في بطاقة الرصيد وبطاقة الحصالة
- 🎯 **عمود اليوم ينبض** في مخطط الأسبوع + رقم "النقص" ينبض بالأحمر
- 🔀 **زر ＋ يدور 45°** عند فتح نافذة الإضافة + شرائح الفلاتر تنبض
- 🕊️ **الحصالة وشعار التطبيق يطفوان** بهدوء مستمر
- 📭 **أيقونات الحالات الفارغة تنبثق** بنابض
- 🎛️ **المفتاح المقسم ينبض** عند تبديل الخيارات
