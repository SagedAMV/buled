# مجرة — النسخة المصغّرة (APK)

ملف التثبيت المضغوط لتطبيق «مجرة» — إدارة المواقع الشخصية (أوفلاين 100٪).

## الملف

| العنصر | القيمة |
|--------|--------|
| الملف | `majarra-mini-2.9.4.apk` (الأحدث) |
| الإصدار | 2.9.4-mini (versionCode 17) |
| الحجم | ~3.7 م.ب (مقابل ~59 م.ب لنسخة التصغير غير المضغوطة) |
| البناء | نمط `mini`: تصغير R8 + تقليص الموارد + توقيع مفتاح التصحيح |
| المتطلبات | Android 11+ (API 30) |
| المصدر | https://github.com/SagedAmV/app_work_kotlin |

## التثبيت

انقل الملف إلى جهازك وافتحه ثم وافق على التثبيت من «مصادر غير معروفة»
إن طُلب ذلك. التوقيع بمفتاح التصحيح يعني أن الجهاز قد يرفض تحديث نسخة
موقعة بمفتاح مختلف — ثبّتها كنسخة مستقلة.

## جلسة البناء (2.9.4)

بُنيت هذه النسخة في جلسة تحقق عميق مستقلة من أخطاء البناء على كود 2.9.4
(تجميع فعلي كامل: Gradle 8.5 + AGP 8.2.2 + Kotlin 1.9.22 + JDK 17):
ترجمة Kotlin وKSP (Room + Hilt) ومترجم Compose وتصغير R8 كامل مع تقليص
الموارد و`lintVital` بلا أي خطأ، و33 اختبار وحدة ناجحًا بلا فشل. تتضمن
هذه النسخة إصلاحات 2.9.4 الثلاث: الرجوع للخلف عند السحب السريع بين
التبويبات، وظهور بيانات التبويبات في منتصف الشاشة بدل أعلاه، وسحب
بطاقات المواقع (مسافة أقصر والتصاق بالإصبع بلا ارتعاش مع نفضة سريعة).
النسخ السابقة (`majarra-mini-2.9.1.apk` و`majarra-mini-2.9.3.apk`)
تبقى في المستودع للأرشفة.
