# مجرة — ملف APK

ملف التثبيت الجاهز لتطبيق **«مجرة»** (إدارة المواقع الشخصية — أوفلاين 100٪).

## الملف

| الملف | الوصف |
|---|---|
| `galaxy-2.4.0-debug.apk` | حزمة الإصدار **2.4.0** موقعة بمفتاح debug — قابلة للتثبيت مباشرة على أي جهاز (المتطلب: Android 11 / API 30 فأحدث). |

## محتوى الإصدار 2.4.0

- إضافة «النزول الطارئ/الاستكشاف»: زر «طارئ» داخل كل موقع، شاشة تسجيل
  بسبب النزول الإلزامي وثلاث نتائج (لا توجد مشكلة / تم حل المشكلة /
  لم يتم حل المشكلة) مع الحقول المشروطة لكل نتيجة والمواد المستخدمة
  من الكتالوج الموحد، وزر حفظ ثابت أسفل الشاشة.
- إصلاح انميشن أرقام الإحصائيات (لم تعد تختفي بعد الدوران).
- فتح الموقع بانميشن واحد بدل اثنين.

## نتيجة التحقق من البناء

آخر تحقق مستقل (18 سبتمبر 2026) — بناء كامل من الصفر عبر `./gradlew`
بعد تثبيت JDK 17 وAndroid SDK (platform 34 + build-tools 34.0.0):

- `assembleDebug` ✅ — `assembleRelease` (R8 + shrinkResources) ✅
- `testDebugUnitTest` ✅ — 24/24 اختبارًا ناجحًا
  (7 لمحقق النزول الطارئ + 11 لسطور المواد + 6 لمحقق الموقع)
- `lintDebug` ✅ — صفر أخطاء، و13 تحذيرًا معلومة لا تمس منطق التطبيق:
  إشعارات «توفر إصدار أحدث» للاعتماديات (10)، سمتا النسخ الاحتياطي
  المقصودتان لتوافق قدم/حداثة الـ API (2)، ومكتبة lint البيئية (1).
